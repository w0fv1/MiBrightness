# MiBrightness

MiBrightness maps Bemfa Cloud light-device commands to the Windows laptop internal-display brightness API.

Highlights:

- Xiaomi / Mi Home voice control through Bemfa Cloud
- System tray UI
- GUI configuration
- Automatic reconnect and heartbeat
- Windows DPAPI encrypted Bemfa secret
- Physical-adapter binding for Clash/Mihomo TUN + Fake-IP environments
- Self-contained single-file Windows x64 build

See the Chinese README for full setup, configuration and troubleshooting instructions.
